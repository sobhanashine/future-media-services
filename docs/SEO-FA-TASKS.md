# برنامه SEO فارسی Future Media Services

## انجام‌شده

- [x] متادیتای اختصاصی فارسی برای صفحه اصلی، خدمات، نمونه‌کارها، درباره، FAQ، تماس و حریم خصوصی.
- [x] تمرکز طبیعی عنوان‌ها و توضیحات روی «طراحی سایت»، «Next.js»، «WordPress Headless» و «مدیریت محتوای اینستاگرام».
- [x] افزودن راهنمای فارسی پاسخ‌محور به صفحه خدمات برای نیت‌های جست‌وجوی واقعی.
- [x] افزودن فایل قیمت فارسی قابل خواندن برای موتورهای جست‌وجو و عامل‌های هوش مصنوعی.
- [x] حفظ `lang="fa"`، `dir="rtl"`، canonical فارسی، hreflang دوطرفه و `x-default`.
- [x] بررسی build، typecheck، lint و تست محتوای فارسی.

## کلمات کلیدی هدف اولیه

- طراحی سایت اختصاصی
- طراحی سایت شرکتی
- طراحی سایت فروشگاهی
- طراحی سایت با Next.js
- WordPress Headless / وردپرس هدلس
- قیمت طراحی سایت
- مدیریت محتوای اینستاگرام
- طراحی پست و استوری اینستاگرام
- تولید ریلز و تقویم محتوایی

این فهرست نقطه شروع است و باید با داده واقعی Search Console، Google Trends و بررسی رقبا اصلاح شود.

## کارهای نیازمند دسترسی یا تصمیم مالک

- [ ] اتصال امن Google Search Console با OAuth فقط به‌صورت read-only و استخراج کوئری، impression، click، CTR و position صفحات فارسی.
- [ ] ثبت و ارسال `https://futuremservices.ir/sitemap.xml` در Search Console.
- [ ] بررسی URL Inspection برای صفحه اصلی، `/services/`، دو صفحه خدمت، `/faq/` و `/work/`.
- [ ] بررسی گزارش Core Web Vitals و Page Experience.
- [ ] تعیین بازار هدف جغرافیایی فقط بر اساس اطلاعات واقعی کسب‌وکار؛ در حال حاضر آدرس یا شهر تأییدشده در سایت ثبت نشده است.
- [ ] تولید ماهانه مقاله یا راهنمای فارسی واقعی درباره طراحی سایت، Next.js، WordPress Headless و مدیریت اینستاگرام؛ بدون صفحات تکراری یا متن ماشینی کم‌ارزش.
- [ ] ساخت اعتبار بیرونی با معرفی واقعی، لینک‌های مرتبط و نمونه‌کارهای قابل تأیید؛ بدون ادعای مشتری، نتیجه یا جایزه تأییدنشده.

## وضعیت داده Search Console

کلید API ارسال‌شده در گفتگو برای داده خصوصی Search Console کافی نیست. طبق مستندات Google، Search Console API برای داده حساب به OAuth 2.0 نیاز دارد. کلید ارسال‌شده باید از Google Cloud لغو شود و هرگز در `.env`، commit، گزارش یا چت ذخیره نشود.
