# برنامهٔ رشد SEO — Future Media Services

آخرین snapshot Search Console: ۲۹ اوت ۲۰۲۶
Property: `sc-domain:futuremservices.ir`

## نقطهٔ شروع

- بازهٔ ۹۰روزهٔ مشاهده‌شده: ۲۸ مه تا ۲۵ اوت ۲۰۲۶
- کلیک: ۱
- نمایش: ۱۴۲
- CTR: ۰٫۷۰٪
- میانگین رتبه: ۱۳٫۸۷
- ۵ مقاله از ۷ مقالهٔ فارسی در URL Inspection ایندکس شده‌اند؛ دو مقالهٔ جدیدتر هنوز در وضعیت unknown/discovered هستند.
- بیشترین نمایش فعلی از صفحه‌های نمونه‌کار `paytakhte-ketab` و `jaheshino` می‌آید؛ این‌ها فرصت بهبود عنوان، توضیح و هدف جست‌وجویی هستند.
- گزارش sitemap مقدار `indexed: 0` نشان می‌دهد، اما URL Inspection برای صفحه‌های اصلی وضعیت indexed دارد؛ این دو گزارش باید بعد از انتشار دوباره کنترل شوند و نباید یکی به‌جای دیگری تفسیر شود.

## کار انجام‌شده در این sprint

- اضافه‌شدن redirect دائمی ۳۰۸ در Worker برای انتقال HTTP به HTTPS و حذف اسلش پایانی از URLهای HTML.
- حفظ رفتار alias فارسی `/fa` تا redirect اضافه ایجاد نشود.
- کوتاه و دقیق‌شدن title و meta description هر ۷ مقالهٔ فارسی برای نمایش بهتر در نتایج.
- اضافه‌شدن تست رگرسیون برای canonical redirect و طول snippetها.
- اعتبارسنجی محلی: ۲۲ تست، typecheck، lint و OpenNext build موفق.

## زمان‌بندی ۳۰روزه

### هفتهٔ اول — انتشار فنی

1. انتشار همین شاخه روی Cloudflare Worker پس از آماده‌بودن احراز هویت deploy.
2. بررسی عمومی `/`, `/blog`, دو مقالهٔ جدید، `/sitemap.xml` و `/robots.txt`.
3. اطمینان از redirect شدن HTTP و URLهای اسلش‌دار به یک URL HTTPS بدون اسلش.
4. ثبت یا submit دوبارهٔ sitemap در Search Console.
5. اجرای URL Inspection برای `nextjs-canonical-url-guide` و `instagram-content-calendar-guide`.

### هفتهٔ دوم — بهبود صفحات دارای تقاضا

1. بازبینی title، H1، توضیح و CTA صفحه‌های `work/paytakhte-ketab` و `work/jaheshino` بر اساس queryهای واقعی.
2. افزودن لینک داخلی معنادار از مقاله‌های مرتبط به خدمت طراحی سایت و صفحهٔ نمونه‌کار مربوط.
3. ادامهٔ انتشار منظم محتوای فارسی با workflowهای موجود دوشنبه و پنجشنبه؛ automation تازه‌ای برای مقاله‌نویسی ساخته نشود.

### هفتهٔ سوم — پوشش موضوعی و اعتبار

1. انتخاب مقالهٔ بعدی از query/pageهایی که impression دارند اما کلیک ندارند.
2. افزودن مثال واقعی، FAQ محدود و منبع رسمی به مقالهٔ منتخب.
3. بازبینی لینک‌های داخلی، anchor text و اتصال هر مقاله به یک خدمت یا نمونه‌کار مرتبط.

### هفتهٔ چهارم — اندازه‌گیری و تصمیم بعدی

1. مقایسهٔ آخرین ۲۸ روز با ۲۸ روز قبل در Search Console.
2. گزارش clicks، impressions، CTR، average position، page، query، device و country.
3. بررسی index status مقاله‌های جدید و وضعیت sitemap.
4. انتخاب حداکثر سه اقدام بعدی بر اساس داده؛ از تغییر هم‌زمان چند متغیر در همهٔ صفحه‌ها پرهیز شود.

## KPIهای پایش

- رشد impression غیر‌برندی برای موضوع‌های طراحی سایت، SEO فنی و مدیریت محتوای اینستاگرام.
- افزایش CTR صفحه‌هایی که میانگین رتبهٔ آن‌ها در بازهٔ ۵ تا ۱۵ است.
- کاهش URLهای مهم با وضعیت unknown/discovered.
- هم‌راستایی sitemap، canonical، redirect و URL Inspection برای صفحه‌های عمومی.
- ثبت کلیک واقعی به صفحهٔ خدمت یا تماس، نه اتکا به impression به‌تنهایی.

## وضعیت و وابستگی‌ها

کد و build در شاخهٔ `codex/seo-growth-sprint` آماده و اعتبارسنجی شده‌اند. deployment عمومی، submit sitemap و درخواست crawl در این مرحله انجام‌شده محسوب نمی‌شوند؛ چون به احراز هویت Cloudflare و وضعیت زندهٔ سایت وابسته‌اند. پایش هفتگی Search Console برای شنبه‌ها ساعت ۱۰:۰۰ به وقت تهران تنظیم می‌شود.
